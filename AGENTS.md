# AGENTS.md

Работай с этим проектом как с продуктовой разработкой для запуска реальной CRM-экосистемы Danil Nails.

## Контекст проекта

Цель: создать систему для маникюрного бизнеса, включающую сайт, клиентский кабинет, CRM, Telegram Mini App, Telegram bot, WhatsApp bot, базу клиентов, записи, расписание, уведомления, оплаты/предоплаты и аналитику.

Сроки:

- soft launch: около 2026-11-03;
- full launch: 2027-01-19 - 2027-02-19.

## Рабочий стиль

- Отвечай по-русски, если пользователь не просит иначе.
- Сначала проверяй существующие документы в `docs/`.
- Не раздувай контекст: сохраняй решения в файлы, а не только в чат.
- Делай изменения маленькими законченными шагами.
- После значимых изменений обновляй roadmap или релевантный документ.
- Для пользовательских сценариев фиксируй: роль, цель, шаги, ошибки, состояние данных.

## Технические предпочтения

Базовый стек, если не принято другое решение:

- TypeScript monorepo;
- Next.js для web/CRM/client cabinet;
- NestJS или Fastify для backend API;
- PostgreSQL + Prisma;
- Redis + BullMQ для очередей и уведомлений;
- grammY или Telegraf для Telegram bot;
- WhatsApp Cloud API напрямую для WhatsApp;
- Docker Compose для локальной разработки.

## Приоритет MVP

Первый запуск должен доказать запись клиента и управление расписанием:

- клиенты;
- услуги;
- мастера;
- рабочее время;
- свободные слоты;
- запись, перенос, отмена;
- CRM-календарь;
- Telegram Mini App или мобильный web booking;
- базовые уведомления.
