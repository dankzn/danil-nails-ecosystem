# Danil Nails CRM Ecosystem

Проект экосистемы для маникюрного бизнеса: сайт, клиентский кабинет, CRM, Telegram Mini App, Telegram bot, WhatsApp bot и единая логика записей/уведомлений.

Старт планирования: 2026-09-19.

## Цели по срокам

- Первый рабочий запуск: примерно через 1,5 месяца, ориентир 2026-11-03.
- Полноценный запуск: через 4-5 месяцев, ориентир 2027-01-19 - 2027-02-19.

## Главный принцип

Все каналы используют одну бизнес-логику:

- сайт и клиентский кабинет;
- CRM для администратора и мастеров;
- Telegram bot и Telegram Mini App;
- WhatsApp bot через WhatsApp Business Platform / Cloud API;
- единая база клиентов, записей, услуг, уведомлений и оплат.
