# MVP Scope

Ориентир первого запуска: 2026-11-03.

## Входит в MVP

- Отдельный deployment и URL закрытой CRM.
- Отдельный deployment и URL клиентского интерфейса записи.
- Авторизация внутренних пользователей CRM.
- Внутренние роли: владелец/основатель, SMM-менеджер, владелец/сооснователь, администратор салона.
- Клиент как отдельный внешний пользователь; отдельная роль мастера активируется позднее при найме мастеров.
- Список клиентов.
- Карточка клиента: ФИО, телефон, email, Telegram, WhatsApp, аллергии, заметки, история визитов, фото ногтей.
- Список услуг: название, категория, длительность, цена, активность.
- Список мастеров: имя, услуги, рабочие часы.
- При появлении отдельной роли мастера её видимость ограничивается только собственными записями.
- CRM-календарь записей.
- Создание записи администратором.
- Ручная модерация и подтверждение записи администратором.
- Клиентская запись через web/mobile интерфейс.
- Запись без регистрации: телефон + Telegram nickname.
- Базовый Telegram bot.
- Telegram Mini App или адаптивный mobile web booking.
- Уведомления о создании, подтверждении, отмене, переносе и напоминании за 1 час.
- Уведомление администратору за день до записей на завтра с задачей подтвердить записи.
- Уведомление мастеру о новой, подтвержденной, отмененной или перенесенной записи.
- Раздельные статусы клиента: публичный статус лояльности и приватные внутренние метки.
- Ведение материалов, цветов, дизайнов и фото по истории клиента.
- Полная базовая аналитика только для владельца/основателя и владельца/сооснователя; SMM получает только разрешённые виджеты главной страницы.
- Docker Compose для локальной разработки.
- Seed-данные для демонстрации.

## Не входит в MVP

- Сложная маркетинговая автоматизация.
- Полноценная программа лояльности.
- Точный учёт расхода материалов по граммам с себестоимостью услуги (уровень SalonScale/Vish) — актуально в первую очередь для окрашивания волос, не для ногтевого сервиса.
- Многофилиальность.
- Сложные WhatsApp-воронки и рассылки.
- WhatsApp как обязательный канал первого запуска.
- Нативные мобильные приложения.
- Онлайн-эквайринг и автоматическая предоплата.

## Дополнительно реализовано сверх исходного MVP

- Базовый учёт ТМЦ: справочник материалов, приход/списание/корректировка остатков, точки дозаказа, автоматическое списание по рецепту услуги при закрытии записи (с возвратом при переоткрытии).
- Лист ожидания: клиенты, которым нет свободного окна, попадают в список; освободившийся слот администратор сначала предлагает им вручную.

## Может попасть в MVP, если останется время

- Отзывы после визита.
- Черный список клиентов.
- Экспорт клиентов/записей.
- Английский и испанский интерфейс сверх технической готовности i18n.
- Публичные страницы сайта: услуги, мастера, галерея, отзывы, контакты.

## Рискованные зоны

- WhatsApp требует настройки Meta Business, номера, webhook и шаблонов.
- Расчет свободных слотов быстро усложняется при разных графиках, перерывах и буферах.
- Перенос/отмена записи должен быть защищен от гонок, чтобы два клиента не заняли один слот.
- Персональные данные требуют аккуратного хранения, разграничения доступа и резервных копий.
- Внутренние статусы клиента должны быть технически недоступны в клиентском кабинете и публичных API.
- Клиентская frontend-сборка не должна содержать внутренние CRM-маршруты или полагаться только на скрытие элементов интерфейса; разграничение обеспечивается отдельными приложениями и серверной авторизацией.
- Логика "не пришел/поздняя отмена -> следующая запись только по предоплате" должна быть явно отражена в правилах клиента и CRM.
