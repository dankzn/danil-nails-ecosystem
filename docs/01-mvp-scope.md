# MVP Scope

Ориентир первого запуска: 2026-11-03.

## Входит в MVP

- Авторизация администратора.
- Список клиентов.
- Карточка клиента: имя, телефон, Telegram/WhatsApp идентификаторы, заметки, история записей.
- Список услуг: название, категория, длительность, цена, активность.
- Список мастеров: имя, услуги, рабочие часы.
- CRM-календарь записей.
- Создание записи администратором.
- Клиентская запись через web/mobile интерфейс.
- Базовый Telegram bot.
- Telegram Mini App или адаптивный mobile web booking.
- Уведомления о создании, подтверждении, отмене и напоминании.
- Базовые роли: owner/admin/master.
- Docker Compose для локальной разработки.
- Seed-данные для демонстрации.

## Не входит в MVP

- Сложная маркетинговая автоматизация.
- Полноценная программа лояльности.
- Склад материалов.
- Многофилиальность.
- Расширенная финансовая аналитика.
- Сложные WhatsApp-воронки и рассылки.
- Нативные мобильные приложения.

## Может попасть в MVP, если останется время

- Онлайн-предоплата.
- Отзывы после визита.
- Черный список клиентов.
- Фото работ в карточке клиента.
- Экспорт клиентов/записей.

## Рискованные зоны

- WhatsApp требует настройки Meta Business, номера, webhook и шаблонов.
- Расчет свободных слотов быстро усложняется при разных графиках, перерывах и буферах.
- Перенос/отмена записи должен быть защищен от гонок, чтобы два клиента не заняли один слот.
- Персональные данные требуют аккуратного хранения, разграничения доступа и резервных копий.
